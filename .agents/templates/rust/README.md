# Rust Template Catalog

This is a future extension point. No Rust templates are currently populated, endorsed, or auto-loaded.

Future references should state toolchain and edition support, crate licenses, feature assumptions, ownership/concurrency implications, compatibility boundaries, and verification commands. They must be optional examples derived from real project needs and subordinate to child-repository policy.

Until references are authored, follow the target's existing modules, error model, async runtime, dependency policy, and official sources selected through clean-room research.
Run any future verification from the resolved clone or task-worktree Cwd; this
catalog does not own worktree or task-document paths.
