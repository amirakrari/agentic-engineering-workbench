# Slidev Reference Library

This directory provides portable guidance for [Slidev](https://sli.dev) presentations.

`SKILL.md` is the task router. The `references/` directory contains just-in-time material for:

- core syntax, headmatter, frontmatter, layouts, and components;
- code blocks, highlighting, live editors, and snippets;
- animations, presenter mode, recording, and remote control;
- Mermaid, PlantUML, and LaTeX diagrams;
- local build, export, hosting, and metadata workflows.

Load only references relevant to the active step. Version-sensitive claims must be checked against the installed Slidev version and official documentation. Publishing or uploading a deck requires explicit user authorization.
